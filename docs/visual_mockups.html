Sengoku Tactics — Visual Mockups

These mockups use the exact colors, sizes, and layouts defined in game_manager.gd and constants.gd. They are HTML/CSS approximations of what Godot will render — not actual game screenshots. Real fonts, kerning, and pixel-snapping will differ slightly when running in Godot, but proportions and colors are accurate.

What's missing from these mockups

  • Animations: cursor pulses, units slide-walk along their move path, damage popups float up, phase banners sweep across the screen.
  • Procedural terrain noise: each tile has a slight per-tile color shift via sin(x*3.7+y*2.3) for visual variation (subtle, omitted from mockup).
  • Combat animation overlay: dimmed background with attacker/defender portraits and a damage tally — appears briefly when units fight.
  • Real fonts: Godot uses its default sans-serif unless you set a theme font. The mockup uses browser serif as a stand-in.
